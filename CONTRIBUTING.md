# Contribution Guidelines

## Coding Standards
- Follow the project's established coding style (e.g., indentation, naming conventions).
- Write clear, concise, and well-documented code.
- Ensure code is tested before submitting.

## Commit Message Format
- Use the imperative mood in the subject line (e.g., "Add feature" instead of "Added feature").
- Include a brief description of the change in the body if necessary.
- Reference any related issues or pull requests in the commit message.

## Pull Request Process
- Ensure your branch is up-to-date with the main branch before opening a pull request.
- Provide a clear description of the changes in the pull request.
- Link to any relevant issues or documentation.

## Development Workflow
1. **Fork the repository** and clone it to your local machine.
2. Create a new branch for your feature or fix.
3. Make your changes and commit them following the message format.
4. Push your changes to your forked repository.
5. Open a pull request against the main repository.

Thank you for contributing!
